# MFA Weather 🌤️

একটি প্রফেশনাল লাইভ আবহাওয়া অ্যাপ যা দেখায়:
- বর্তমান তাপমাত্রা, আর্দ্রতা, বাতাসের গতি
- বৃষ্টির পরিমাণ ও সম্ভাবনা
- ৫ দিনের আবহাওয়ার পূর্বাভাস
- ঘণ্টাভিত্তিক আপডেট

## ফিচারসমূহ ✨
- 🌙 ডার্ক/লাইট থিম
- 🌐 বাংলা/ইংরেজি ভাষা সাপোর্ট
- 📱 সম্পূর্ণ মোবাইল রেসপনসিভ
- 🎯 লোকেশন ভিত্তিক আবহাওয়া
- 🔄 রিয়েল টাইম আপডেট

## প্রযুক্তি ব্যবহার 🛠️
- HTML5
- CSS3 (গ্রিড, ফ্লেক্স, অ্যানিমেশন)
- JavaScript (ES6+)
- OpenMeteo API
